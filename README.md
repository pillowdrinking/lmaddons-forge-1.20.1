# LM Addons

An addon mod for **Legendary Monsters**, enhancing the Soul Great Sword.
**传奇生物（Legendary Monsters）的附属模组，强化灵魂巨剑。**


## Features / 功能

- Soul Fracture enhancement (max level & duration configurable)
- Parry enhancement: invulnerability frames, Soul Rage, perfect parry rewards
- Phantom Dagger enhancement: auto-targeting, lifesteal, kill effects, configurable lifetime

- 碎魂强化（最高等级与持续时间可配置）
- 弹反强化：无敌帧、灵魂之怒、完美格挡奖励
- 幻影匕首强化：自动追踪、吸血、击杀特效、存活时间可配置

## Dependencies / 依赖

- Minecraft **1.20.1**
- Forge **47.x**
- [Legendary Monsters](https://www.curseforge.com/minecraft/mc-mods/legendary-monsters) **2.1.x**


## Configuration / 配置

After first launch, a config file will be generated at:
config/lmaddons-common.toml
首次启动后会在 `config/lmaddons-common.toml` 生成配置文件。

All options are bilingual (English + Chinese) with clear descriptions.
所有配置项均为中英双语注释，并带有详细说明。

## Build / 构建

```bash
./gradlew build
```

Output is in `build/libs/`.

构建产物位于 `build/libs/`。
